# Icon assets

- `deepseek-blue.ico` is the public favicon served by `https://www.deepseek.com/favicon.ico`.
- `deepseek-black.svg` uses the icon-only vector path embedded in the public DeepSeek homepage logo at `https://www.deepseek.com/`, with the page's `currentColor` resolved to black.
- `deepseek-black.ico` is a deterministic black rasterization of that official icon shape, generated by `cargo run -p dsh-atelier --example generate_black_icon` so it can be copied directly to `~/.atelier/icon.ico`.

These files represent the DeepSeek brand and may be subject to DeepSeek's trademark and brand-use rules. They are kept separate from DSH Atelier's MIT-licensed source code.
